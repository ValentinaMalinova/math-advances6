## 🔄 Data Flow

```
User Interaction
       ↓
   Browser Event
       ↓
   JavaScript Function
       ↓
   DOM Update
       ↓
   CSS Animation
       ↓
   Visual Feedback
       ↓
  User Sees Result

Пример:
Кликване на Game1 Button
       ↓
checkGame1() функция
       ↓
Сравнение на input с очаквания отговор
       ↓
document.getElementById('game1-feedback')
       ↓
Добавяне на CSS класс (.show, .success/.error)
       ↓
Появи съобщението с анимация
       ↓
Пользователь прочитает результат

```
